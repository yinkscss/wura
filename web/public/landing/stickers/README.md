# Landing stickers

Decorative cutouts for the landing hero sides (Payrit-style: white-outlined photo stickers on the left and right edges). They are AI-generated images, not photos of real products, and are not wired into the page yet.

Every sticker has a transparent background and keeps its white sticker outline. Each comes as `.webp` (use this on the site) and `.png` (source / fallback).

| File | What it is |
| --- | --- |
| `black-star-gate` | Black Star Gate, Accra (the generated pillars carry stray letters) |
| `big-ben` | Big Ben, London |
| `burj-khalifa` | Burj Khalifa, Dubai |
| `statue-of-liberty` | Statue of Liberty, New York |
| `pyramid-sphinx` | Pyramid and Sphinx, Giza |
| `concrete-monument` | Concrete twin-pillar monument; fades out at the bottom |
| `camera` | Vintage camera |
| `phone-currencies` | Phone showing a currency list (example UI) |
| `coin-usdc-blue`, `coin-euro`, `coin-dollar-teal`, `coin-usdc-lavender` | Coin badges |
| `sky-bg` | Soft cloud sky, 1280×720 (`.webp` / `.jpg`, no transparency) |

Decorative only: render with `alt=""` and `aria-hidden="true"`.
